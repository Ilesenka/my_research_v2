## Артефакт 6. Проверка усреднения сечения

Проверялось вычисление сечения фотоядерной реакции, усреднённого по спектру фотонов. Использованы модельные зависимости с известным аналитическим ответом: линейно возрастающее сечение и линейно убывающий спектр. Точное среднее для этой модели равно трети максимального сечения.

Расчёт выполнялся составным методом трапеций на равномерной сетке. Использованы три набора параметров и шесть размеров сетки — от 10 до 320 интервалов, всего **18 расчётов**.

Верификатор проверяет допустимость входов, построение сетки, отдельные интегралы, точность среднего и порядок сходимости. Критерии принятия записаны в методике; выполнены этапы `dry → smoke → sweep → full`.

| Исправная реализация | **182 теста пройдены**, код 0 |
| Порядок сходимости | Около **2.0000**; согласованный заранее интервал: 1.9–2.1 |
| Относительная погрешность при 320 интервалах | **9.766e-6**; ниже согласованного заранее порога 1e-4 |

## Артефакт 7. Проверка верификатора EXFOR

**Направление:** вычислительное — B, верификатор на свойствах с использованием Hypothesis.

Для этого этапа автором был выбран другой объект (отличный от используемого на неделе 6 и в примерах курса) — верификатор данных, выгруженных из базы ядерных данных EXFOR. Проверка экспериментальной базы непосредственно полезна для написания учебной статьи.

На специально подготовленных записях проверялось, замечает ли верификатор искажение исходных значений, неверный перевод единиц, ошибки отбора и расхождения между основной таблицей и очередью ручной проверки. Задача разделена на независимые подцели; для каждой определены допустимые входы и команда проверки.

| Что проверяется | Что подтверждено |
|---|---|
| Значения изомерных отношений IR | Например, 25 процентов переводятся в 0.25; значение 0 не считается пропуском |
| Единицы энергии | Одна энергия, записанная в разных единицах, распознаётся одинаково: например, 20 МэВ = 20000 кэВ |
| Отбор измерений | Граничные значения входят в выборку; расширение диапазона не исключает ранее принятые записи |
| Верхние пределы | Запись `IR ≤ 0.001` нельзя заменить на `IR = 0.001` (иначе — ошибка) |
| Очередь ручной проверки | В очереди должны быть все записи, требующие проверки, и никаких больше; их поля должны совпадать с основной таблицей |
| Отклонённые записи | Исходные данные сохраняются; у каждой отклонённой записи должна быть непустая причина отклонения |
| Полнота таблицы | Если в исходниках есть ожидаемые измерения, пустая основная таблица считается ошибкой |

Для семи свойств написаны тесты с Hypothesis. Каждому соответствует намеренная ошибка в отдельной копии реализации: **все семь ошибок обнаружены**. Набор недели 7 содержит **15 успешных тестов**, включая семь проверок обнаружения ошибок и дополнительную проверку пустых исходников. Встроенные самопроверки верификатора — **11 успешных**.

Попытки и исправления проверочных стендов записаны в журнале `ATTEMPTS.md`. Трёх неудачных попыток по одной подцели не было; пересмотр плана не потребовался. Сравнение веток подтвердило, что проверки не ослаблялись: содержимое `checks/` осталось неизменным.

В рамках задачи проверялось выполнение заданных свойств верификатора. Сверка данных таблицы EXFOR с оригинальными записями не проводилась.
