# Собрать экспериментальные изомерные отношения

Запрос пользователя: «собрать экспериментальные изомерные отношения из основной статьи и готовых материалов по статьям Палванова».

Готово, когда: создан results/artefact4/isomeric_ratios.csv с указанными столбцами и строками всех экспериментальных измерений из таблицы 3 основной статьи и численных значений из results/artefact2/table.csv; повторения, пропуски и ограничения записаны в notes; выполнена строгая проверка проекта.
Не входит: открытие PDF, поиск сведений в интернете, повторная научная сверка, извлечение дополнительных точек из графиков, включение TALYS.

## План
1. Извлечь экспериментальные строки таблицы 3 из TXT основной статьи
2. Разнести численные списки Палванова по отдельным измерениям
3. Собрать и проверить CSV, включая повторы и пропуски
4. Обновить граф, память проекта и выполнить проверки

## Итог

Собраны экспериментальные IR из таблицы 3 основной статьи и материалов Палванова в `results/artefact4/isomeric_ratios.csv`; в наборе 19 строк. Повторения 2007/2011 сохранены отдельно; для натуральных смесей target записан как natX, reaction содержит только канал (γ,...), а каналы объединённых измерений отражены в notes.

Принято пользователем: «Принимаю результат второй сессии: таблицу экспериментальных изомерных отношений и обновлённый граф проекта.»
