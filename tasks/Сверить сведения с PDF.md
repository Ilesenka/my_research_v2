# Сверить сведения с PDF

Подзадача разбора статьи как источника: повторно сверить непосредственно с PDF сведения, определяющие пригодность данных для проекта (реакции, продукты, диапазоны энергий, формат IR, условия и ограничения).

Готово, когда: в results/artefact4/source_review.md записаны способ и итог повторной сверки ключевых сведений с PDF.
Не входит: сверка численных значений IR.

## Итог
В обзоре раздел 5: способ — повторное чтение страниц 1, 4, 5, 6, 7 и поиск по тексту (pdf_search по строкам «высокоспиновом», «Ym», «45 до», «обогащен», «шесть», «Гисене»); итог — таблица из семи сверенных сведений, расхождений не выявлено. Проверено: файл results/artefact4/source_review.md, раздел 5.
