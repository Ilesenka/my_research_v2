# Энергии измерений цитируемых работ указаны не полностью

Для работ [31–34] в тексте указаны наборы энергий (45–65, 55/60/65, 50/55/60/64, 45/50/55/60 МэВ, с. 6–7). Все строки табл. 3, включая 141Nd и 178Ta из [35], отнесены к Eᵐ = 55 МэВ её заголовком (с. 6); более широкие наборы энергий не создают неоднозначности в энергии строк таблицы. Сохраняющееся ограничение: данные работ [30–35] рассматриваются по вторичному источнику, их первичные публикации пока не проверены.
