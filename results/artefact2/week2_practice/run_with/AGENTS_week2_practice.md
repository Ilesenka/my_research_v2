# AGENTS.md — обработка спектров

Учебный проект: четыре спектра поглощения, у каждого от одного до трёх пиков.

## 0. Цель и образ результата
Положения и ширины (FWHM) всех пиков во всех файлах `data/*.txt`.

В конце в проекте существуют:
- `src/peaks.py` — скрипт расчёта; запускается командой `python src/peaks.py`;
- `results/peaks.csv` — столбцы `file, center_nm, fwhm_nm`, одна строка на пик.

Ничего больше создавать не надо.

## 1. Критерий готовности
```
python checks/check_peaks.py
```
Код 0 — работа принята. Вызови проверку перед окончательным ответом.

## 2. Карта проекта
`data/` — спектры: столбцы `wavelength_nm`, `intensity`, разделитель — табуляция.
Чего агент не знает сам: пиком считается максимум выше уровня шума в 5 раз;
у спектров есть слабый линейный фон.

## 3. Инструменты и границы
Python, numpy, scipy. Сеть не нужна.

## 4. Запреты
1. Не изменять файлы в `data/`. `[среда]` — `chmod -R a-w data`
2. Не читать и не изменять `checks/`. `[окно]`
3. Не подбирать параметры под прохождение проверки. `[окно]`

## 5. Протокол и режим работы
Режим — ReAct: прочитать данные, написать скрипт, запустить, посмотреть результат.
После каждого изменения скрипта — запуск и проверка.

## 6. Память
В `diary.md` — одна запись в конце: что сделано, результат проверки.

## 7. Остановка и бюджет
- Не больше 15 шагов.
- Две неудачи проверки подряд по одной причине — остановись и опиши причину.
