# Artefact 1 — проверка расчёта изомерного отношения (синтетические данные)

> **ВНИМАНИЕ:** все входные данные и результаты в этом файле — **синтетические**,
> приведены для иллюстрации порядка величин и **не являются данными EXFOR**.
> Они не записаны в `initial_data/` и `unified_data/`.

## Формулы

Изомерное отношение:

IR = σ<sub>m</sub> / σ<sub>g</sub>

Неопределённость при **независимых** неопределённостях сечений
(стандартное правило распространения ошибок для частного):

δIR / IR = √( (δσ<sub>m</sub> / σ<sub>m</sub>)² + (δσ<sub>g</sub> / σ<sub>g</sub>)² )

δIR = IR · √( (δσ<sub>m</sub> / σ<sub>m</sub>)² + (δσ<sub>g</sub> / σ<sub>g</sub>)² )

### Допущение
Неопределённости δσ<sub>m</sub> и δσ<sub>g</sub> считаются **независимыми**
(ковариационный член равен нулю). Это допущение указано явно;
для реальных данных EXFOR независимость следует проверять отдельно.

## Пример 1

Входные (синтетические): σ<sub>m</sub> = 40 ± 4 mb, σ<sub>g</sub> = 20 ± 2 mb.

IR = 40 / 20 = 2.00

δIR / IR = √( (4/40)² + (2/20)² ) = √( 0.01 + 0.01 ) = √0.02 ≈ 0.1414

δIR = 2.00 × 0.1414 ≈ 0.28

**Результат:** IR = 2.00 ± 0.28 (относительная неопределённость ≈ 14%).

## Пример 2

Входные (синтетические): σ<sub>m</sub> = 30 ± 3 mb, σ<sub>g</sub> = 60 ± 6 mb.

IR = 30 / 60 = 0.50

δIR / IR = √( (3/30)² + (6/60)² ) = √( 0.01 + 0.01 ) = √0.02 ≈ 0.1414

δIR = 0.50 × 0.1414 ≈ 0.07

**Результат:** IR = 0.50 ± 0.07 (относительная неопределённость ≈ 14%).
