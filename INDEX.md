# INDEX.md — где что лежит

- `AGENTS.md` — цель проекта, критерии готовности, соглашения и правила работы агента.
- `STATUS.md` — текущее состояние исследования, следующие действия и действующие ограничения; читать в начале сессии.
- `diary.md` — история работы, проверки результатов и замечания пользователя; только дописывается.
- `initial_data/` — каталог для исходных записей EXFOR; существующие записи не изменять.
- `unified_data/` — каталог для данных, приведённых к согласованному формату.
- `paper/` — научные статьи и другие материалы источников; PDF доступны только для чтения.
- `paper/library_artefact2/` — статьи по изомерным отношениям в реакции ¹⁴²Nd(γ,n)¹⁴¹m,gNd.
- `paper/library_artefact3/My_paper_to_compress.pdf` — основная статья проекта.
- `memory/` — сжатые сведения из источников и сверка утверждений с оригиналами.
- `memory/L2.md` — основные тезисы основной статьи проекта и таблица сверки с оригиналом; использовать для знакомства с содержанием, точные сведения проверять по PDF.
- `cascade.sh` — скрипт каскадного сжатия статьи: разбиение текста на части и создание уровней L1 → L2 → L3.
- `src/` — каталог для кода обработки данных, расчётов и построения графиков.
- `results/` — каталог для результатов: таблиц, графиков и текстовых отчётов.
- `checks/` — скрипты проверки результатов; разрешены чтение и запуск, изменение запрещено.
- `ontology.yaml` — вопросы графа проекта, классы, допустимые связи, статусы задач и проверяемые правила.
- `.obsidian/` — настройки хранилища Obsidian: `app.json` (показ всех файлов) и `graph.json` (вид «Граф»).
- `ontology/` — заметки классов графа, по одной на каждый класс из `ontology.yaml`.
- `tasks/` — заметки задач и подзадач с условиями готовности и статусами.
- `notes/` — заметки объектов работы: источников, обработок, результатов, проверок и ограничений.
- `results/artefact4/source_review.md` — обзор статьи `paper/library_artefact3/My_paper_to_compress.pdf` как источника: реакции, продукты, энергии, формат IR, условия и ограничения.
- `results/artefact4/isomeric_ratios.csv` — экспериментальные IR из таблицы 3 основной статьи и `results/artefact2/table.csv` по Палванову; TALYS исключён.
