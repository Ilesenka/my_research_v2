# L2 — тезисы

1. Фотоядерные реакции на естественной смеси изотопов ртути исследованы активационным методом при энергии электронов E_m = 55 МэВ (с. 1).
2. Изомерные отношения определены для 195,197Hg и 198,200Au; IR определён как σ_h/σ_l, а в эксперименте измеряется как Y_h/Y_l (с. 1, 4).
3. Облучение длилось 11 мин при среднем токе 16.7 нА, мишень-конвертор — вольфрам толщиной 0.2 мм (с. 2).
4. Выходы Y(E_m) рассчитаны как свёртка тормозного спектра W(E,E_m) с сечением σ(E), при этом W получен по GEANT4 (с. 3–4).
5. По расчётам TALYS для 195Hg вклады реакций (γ,1n) и (γ,4n) составляют 18% и 28%, доминирует 198Hg(γ,3n) — 47%; для 197Hg 199Hg(γ,2n) даёт 26%, 198Hg(γ,1n) — 65% (с. 5).
6. Для 198,200Au расчёт TALYS превышает эксперимент в 30–40 раз; в расчёте использована функция Strength 9 (SMLO) (с. 5).
7. Парциальные выходы при E_m = 55 МэВ аппроксимированы как Y/Ytot = exp(−A∆I² − B∆I) от ∆I = |Ip − It|, выходы убывают с ростом ∆I (с. 8).
8. Расчёт TALYS расходится с экспериментом при ∆I > 4 (с. 8).
9. Вторая аппроксимация Y/Ytot = exp(−A·|Ip(Ip+1) − It(It+1)|) показывает небольшое, но статистически значимое, уменьшение разброса при |Ip(Ip+1) − It(It+1)| < 60, при значениях ≥ 60 надёжность снижается (с. 8).
10. Для ¹⁴²Nd(γ,1n)¹⁴¹m,gNd мишень natNd даёт почти двукратное увеличение изомерного отношения против обогащённой ¹⁴²Nd (с. 8).
